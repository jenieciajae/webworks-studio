## Project Summary

Briefly summarize the client need and the MVP you are building.

Hill Country Coffee is an independent coffee company based in Central Texas that wants a modern, user-friendly website. The MVP includes four pages: Home, Menu, Locations, and About. The website will help customers explore the menu, learn about the business, and find important café information while providing a responsive and accessible experience.

## Technology Used

### HTML

HTML is used to structure the four website pages and organize content. Semantic elements are used where appropriate to support accessibility and organization.

### CSS

Custom CSS is used for the website's visual design, including colors, typography, navigation, page layouts, buttons, and responsive breakpoints. No CSS framework is being used.

### JavaScript

Limited JavaScript is used to automatically update the current year in the website footer. The MVP does not currently require complex interactive features.
