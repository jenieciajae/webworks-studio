# 1. Client & Project Summary

In approximately 100–150 words, summarize:

- who Hill Country Coffee is;
- why the website project is needed;
- who the site serves;
- the central problem WebWorks Studio needs to solve.

Hill Country Coffee is an independent coffee company based in Central Texas that wants to create a more modern and user-friendly website. The website is needed to help customers learn more about the business, explore its menu, and find important information like café locations and hours. It will serve both regular customers and people visiting the Hill Country area who may be discovering the company for the first time. The main goal for WebWorks Studio is to create a website that is easy to navigate, works well on mobile devices, and makes information easy to find. The site should also reflect the company's welcoming atmosphere and connection to the local community.

# 3. Target Users & User Needs

## Maya — Mobile Regular

**Context:**  
Maya is a regular customer who usually visits the website on her smartphone while she's out.

**Primary goal:**  
Quickly find café hours, locations, and menu information.

**Important information/tasks:**  
Check whether a café is open, find the nearest location, and browse available drinks and food.

**Likely friction:**

Renee likes to research a business before visiting and may use either a desktop computer or smartphone.

Find clear and detailed information so she can plan her visit.

**Important information/tasks:**  
Read about the company, review menu options, and check important café information.

**Likely friction:**  
Small text, confusing organization, or missing information that makes it difficult to plan ahead.

**Design/accessibility implication:**  
The website should use readable text, clear headings, accessible colors, and an organized structure.

# 8. Accessibility Requirements

Define accessibility requirements before design/development begins.

At minimum, address:

## Semantic Structure

Use semantic HTML elements such as header, nav, main, and footer to organize the website and make it easier for assistive technologies to understand.

## Heading Structure

Use headings in a logical order (H1, H2, H3) so visitors can easily understand how the content is organized.

## Keyboard Access

All navigation links and interactive elements must be usable with a keyboard without requiring a mouse.

## Visible Focus

Interactive elements must have a visible focus indicator so keyboard users can tell which element they are selecting.

## Color Contrast

Text and background colors must have enough contrast to make information easy to read.

## Images / Alternative Text

Meaningful images must include descriptive alternative text. Decorative images should use empty alt attributes.

## Links & Buttons

Links and buttons must have clear labels that explain where they go or what action they perform.

## Responsive Reflow / Zoom

The website must remain usable when visitors zoom in, enlarge text, or view it on smaller screens without unnecessary horizontal scrolling.

## Interactive Components / Forms

The MVP will not include complex interactive components or forms. Any links or buttons included must still be accessible by keyboard and have clear labels.

## Accessibility QA

Test the website using keyboard navigation, browser zoom, and accessibility inspection tools. Check color contrast, heading structure, and image alternative text before delivery.
